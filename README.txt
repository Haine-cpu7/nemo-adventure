ねもの冒険記録 v0.3
====================

Nemo Collectionの世界観で遊ぶ「死なないローグライク」Webゲームです。
インストール不要。静的HTML/CSS/JavaScriptだけで動きます。

v0.3の追加
- ゲーム専用「ゲストねも」5体を実画像で実装
- さくらねも：バランス型（げんき11 / 回復+1）
- メカねも：探索型（レア発見率アップ）
- ぴんくねも：幸運型（ときどき追加のおみやげ）
- ちあふるねも：前進型（最大げんき12）
- しずかねも：安全型（ダメージ軽減）
- 冒険中・帰還画面・新しい冒険履歴にもねも画像を表示
- 「NFTなしで遊ぶ / NFTねもで遊ぶ（COMING SOON）」の入口を追加
- 既存v0.2のブラウザ記録は同じlocalStorageキーを使うため基本的に引き継ぎます

GitHub Pagesへの更新方法
1. このZIPを解凍
2. GitHubの nemo-adventure リポジトリを開く
3. index.html / app.js / styles.css / README.txt と assets フォルダをアップロード
4. 同名ファイルは置き換える
5. Commit changes
6. Pagesは既に有効なら、しばらく待って再読み込み

重要
assets フォルダを忘れると、ねもの画像が表示されません。
