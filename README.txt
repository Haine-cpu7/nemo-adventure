ねも死なないローグライク v0.11

Webブラウザで遊べる、ねもちゃんの「死なないローグライク」。
NFTなしでもゲストねもで遊べます。
NemoCollection2023ホルダーは、自分のNFTねもで各ダンジョンのより深いROOMとHolder限定ルートへ進めます。

v0.11変更点：高難易度ダンジョンを本気で再調整
- どんぐりの森：これまで通り安全。初心者・図鑑集め向け
- 古い倉庫：ROOM6以降で罠と環境ダメージが少し増える
- 忘れられた温泉洞：基礎危険度を大幅アップ。ROOM5 / 8 / 11で危険度が段階上昇
- 温泉洞：回復効率を0.55倍まで低下。深部では入室時にも蒸気・岩場による消耗が発生
- 記録者の地下回廊：基礎危険度を大幅アップ。ROOM4 / 7 / 10でさらに危険化
- 地下回廊：回復効率0.40倍。最奥到達は「珍しい成功回」を想定
- 慎重・回復系の選択でも、高難易度では環境ダメージを完全には無効化できない
- げんき0でも死亡はせず、その場で冒険終了・帰還
- 入室時の危険は画面本文と冒険ログの両方に表示

狙い：
- 森はほぼ完走できる
- 倉庫はたまに途中帰還
- 温泉洞は途中帰還が普通に起こる
- 地下回廊は最奥到達がレア
